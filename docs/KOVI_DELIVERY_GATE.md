# KOVI Delivery Gate — Finance

KOVIAN Finance owns financial facts, transactions, accounts, budgets, goals, debts, assets and forecasting inputs.

## Required gates
- Maven tests
- Frontend lint
- Frontend build
- Frontend tests
- Chromium desktop smoke
- Chromium mobile smoke for responsive changes
- Security/dependency validation

KOVI provides generative reasoning and orchestration. Finance remains authoritative for financial facts and deterministic calculations.

AI output is advisory unless an explicit authorized product workflow applies. Mutations require authorization, idempotency and audit evidence.
