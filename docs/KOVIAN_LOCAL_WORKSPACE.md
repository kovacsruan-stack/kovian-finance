# KOVIAN Local Workspace Reference

The canonical local workspace is maintained by the KOVIAN repository.

- Workspace root: `D:\\GitHub`
- KOVIAN: `D:\\GitHub\\KOVIAN`
- KOVI AI: `D:\\GitHub\\kovi-ai`
- KOVIAN Fitness: `D:\\GitHub\\kovian-fitness`
- KOVIAN Finance: `D:\\GitHub\\kovian-finance`
- Development branch: `feat/local-dev-orchestration`
- Git client: GitHub Desktop

Local automation must preserve branches and uncommitted changes. It must never automatically checkout, reset, rebase, merge, stash or clean a repository. Production execution is prohibited by the local validation workflow.

The KOVIAN repository contains the canonical launcher: `scripts/kovian-local.mjs`.
